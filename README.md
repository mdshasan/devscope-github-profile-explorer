# DevScope — GitHub Profile Explorer

A responsive GitHub profile explorer built with **HTML, CSS, and vanilla JavaScript**. Search a username to view public profile details and repositories through the GitHub REST API.

## Features
- Search GitHub users and view profile statistics.
- Browse repositories, stars, forks, and languages.
- Sort repositories and load more results.
- Responsive layout with loading and error states.

## Run locally
Clone or download the repository, then open `index.html` using a local development server such as VS Code Live Server. No build step or API key is required.

## Built with
HTML5 · CSS3 · JavaScript ES Modules · GitHub REST API

**Note:** Uses GitHub's unauthenticated API rate limits and displays public GitHub data only.
